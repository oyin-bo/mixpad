# Link and Image Token Tests

## Basic bracket tokens

Single open bracket:
[
1
@1 LinkOpen "["

Single close bracket:
]
1
@1 LinkClose "]"

Single open parenthesis:
(
1
@1 LinkDestOpen "("

Single close parenthesis:
)
1
@1 LinkDestClose ")"

## Image marker

Exclamation before open bracket:
![
12
@1 ImageMarker "!"
@2 LinkOpen "["

Exclamation not followed by bracket (inline text):
! text
1
@1 InlineText "! text"

Exclamation followed by parenthesis (not image marker):
!(
12
@1 InlineText "!"
@2 LinkDestOpen "("

Exclamation at end of input (no following character):
!
1
@1 InlineText "!"

Double exclamation before bracket:
!![
123
@1 InlineText "!"
@2 ImageMarker "!"
@3 LinkOpen "["

## Task list takes priority over link open

Task list unchecked still works:
- [ ] task
1 2   3
@1 BulletListMarker "-"
@2 TaskListMarker "[ ]"
@3 InlineText "task"

Task list checked still works:
- [x] done
1 2   3
@1 BulletListMarker "-"
@2 TaskListMarker "[x]"
@3 InlineText "done"

Bare task list still works:
[ ] task
1   2
@1 TaskListMarker "[ ]"
@2 InlineText "task"
