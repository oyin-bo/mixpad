# Hard Line Break Scanning in `scan0`

## Overview
Hard line breaks in CommonMark are triggered by:
- A backslash `\` at the end of a line (before a newline).
- Two or more spaces (`  `) at the end of a line (before a newline).

## Token
`HardLineBreak` (resolved kind at semantic level or provisional marker at scan0 level).

## scan0 Responsibilities
- **Trailing Backslash**: Check if `\` is immediately followed by a newline.
- **Trailing Spaces**: Check if a `Whitespace` token with length >= 2 is followed by a newline.

## Implementation Pattern
```javascript
case 92 /* \ */:
  // Is this a trailing backslash followed by newline?
  if (offset < end && (input.charCodeAt(offset) === 10 || input.charCodeAt(offset) === 13)) {
    // Escaped line break
    output.push(1 | Escaped);
    return 1;
  }
  break;

case 32 /* space */: {
  // Whitespace is already handled.
  // The semantic phase will identify trailing whitespace >= 2 before NewLine
  // as a hard break.
}
```

## Semantic Phase Handling
The semantic phase identifies the pattern `Whitespace(length >= 2)` + `NewLine` as a `HardLineBreak`. Similarly, `Escaped` (backslash) + `NewLine` is a `HardLineBreak`.
1. Materializes the break as a `<br />` equivalent.
2. Ensures leading spaces on subsequent lines are handled correctly (potentially as part of a list or indentation).
