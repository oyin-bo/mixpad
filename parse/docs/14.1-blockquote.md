# Blockquote Scanning in `scan0`

## Overview
Blockquotes are initiated by a `>` character at the beginning of a line, potentially preceded by up to 3 spaces of indentation.

## scan0 Responsibilities
- **Indentation Check**: Ensure `>` is preceded by max 3 spaces. 4+ spaces would classify as an indented code block or continuation.
- **Token**: `BlockquoteMarker`.
- **Length**: 1.
- **Metadata**: No additional metadata required for the marker itself.

## Decision Points
- If `>` is followed by a space, `scan0` returns consumed length 2 (marker + space).
- If `>` is *not* followed by a space, `scan0` returns consumed length 1. CommonMark allows `>text`.
- The semantic layer will handle nesting and lazy continuation lines.

## Implementation Pattern
```javascript
export function scanBlockquote(input, start, end, output) {
  const char = input.charCodeAt(start);
  if (char !== 62 /* > */) return 0;

  // Indentation check
  const lineStart = findLineStart(input, start);
  const lineIndent = countIndentation(input, lineStart, start);
  if (lineIndent > 3) return 0;

  output.push(1 | BlockquoteMarker);
  
  // Consume a single space following the > if present
  if (start + 1 < end && input.charCodeAt(start + 1) === 32 /* space */) {
    return 2;
  }
  return 1;
}
```
