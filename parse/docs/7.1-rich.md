# High-End Semantic AST Refinement (Rich Model)

This document specifies the upgrade from a toy 'BaseNode' facade to a high-end, IDE-grade AST architecture for MixPad.

## 1. High-End Arena Architecture (Stride 6)

To support efficient bidirectional navigation (standard in high-end engines like Roslyn), the **Green Arena** uses a \NODE_STRIDE = 6\.

Each node in the \Uint32Array\ buffer occupies 6 slots:
1. **TYPE**: Token kind (from \scan-tokens.js\).
2. **WIDTH**: Length of the node in UTF-16 code units.
3. **FIRST_CHILD**: Buffer index of the first child, or 0.
4. **NEXT_SIBLING**: Buffer index of the next sibling, or 0.
5. **PARENT**: Buffer index of the parent node.
6. **PREV_SIBLING**: Buffer index of the previous sibling (enabling \O(1)\ backward traversal).

## 2. Text Coalescing (The Facade Layer)

The 'Red Facade' provides a consolidated view of the fragmented Green Arena:
- **TextNode**: Coalesces consecutive tokens like \InlineText\, \Whitespace\, and \NewLine\ into a single semantic node.
- This prevents the "token soup" problem where every space is a node, while keeping the Arena flat and simple.

## 3. Exhaustive Semantic Node Hierarchy

Every significant Markdown construct is represented by a specialized subclass of \BaseNode\.

### Block Level Nodes
- **DocumentNode**: The root of the AST.
- **AtxHeadingNode**:
    - \getLevel()\: Re-scans source to count \#\.
- **SetextHeadingNode**:
    - \getLevel()\: Re-scans underline (\===\ vs \---\).
- **ParagraphNode**: A collection of inline children.
- **BlockquoteNode**: Includes children and marker analysis (e.g., \>\).
- **BulletListNode** / **OrderedListNode**:
    - \isTight()\: Analyzes child spacing.
- **ListItemNode**:
    - \getMarker()\: Returns \-\, \*\, \+\ or \1.\.
    - \isChecked()\: For task lists (\[ ]\ vs \[x]\).
- **FencedCodeBlockNode**:
    - \getLanguage()\: Extracts info string.
    - \getContent()\: Returns the raw code content.
- **TableNode**:
    - \getRows()\, \getColumns()\, \getAlignment(column)\.
- **ThematicBreakNode**: (\---\, \***\, \___\).
- **FrontmatterNode**: YAML/TOML blocks.
- **FormulaBlockNode**: (Math blocks delimited by \$$\).

### Inline Level Nodes
- **TextNode**: The workhorse (coalesced \InlineText\, \Whitespace\, \NewLine\).
- **EmphasisNode** / **StrongNode** / **StrikethroughNode**.
- **LinkNode** / **ImageNode**:
    - \getDestination()\: Re-scans \LinkDestination\ range.
    - \getTitle()\: Re-scans \LinkTitle\ range.
    - \getLabel()\: Accesses \LinkLabel\ child.
- **InlineCodeNode**: Derived from \BacktickBoundary\ and \InlineCode\.
- **EntityNode**: Covers \EntityNamed\, \EntityDecimal\, \EntityHex\.
    - \getValue()\: Decodes the entity.
- **EscapedNode**: Represents \\\x\ characters.
- **AutolinkNode**: Angle brackets, Raw URLs, WWW, and Email variations.
- **InlineFormulaNode**: Inline math (\$...\).

### HTML / XML Nodes
- **HTMLTagNode**:
    - \getTagName()\, \isClosing()\, \getAttributes()\.
    - \isSelfClosing()\.
- **HTMLCommentNode**.
- **HTMLCDataNode**.
- **HTMLDocTypeNode**.
- **HTMLRawTextNode**: For content inside \<script>\ or \<style>\.
- **XmlPINode**: Processing Instructions like \<?php ... ?>\.

## 4. The Re-Scan Principle

To keep memory footprint minimal, complex properties are not stored in the buffer. Instead, the \BaseNode\ facades use \sourceFile.getText(node)\ and re-examine the string on demand.

Example:
\\\javascript
class AtxHeadingNode extends BaseNode {
    getLevel() {
        const text = this.sourceFile.getText(this);
        let i = 0;
        while (i < text.length && text[i] === '#') i++;
        return i;
    }
}
\\\

## 5. Bidirectional Navigation

With \PARENT\ and \PREV_SIBLING\ indices, the AST supports:
- \getParent()\: Immediate access to the parent container.
- \getPreviousSibling()\: Backward iteration.
- \ncestors()\: Generator for upward traversal.

## 6. Monomorphic Optimization

All specialized nodes are instantiated via a factory that ensures they share a common hidden class (Map) in the JS engine as much as possible, while providing the specific semantic API for their type.
