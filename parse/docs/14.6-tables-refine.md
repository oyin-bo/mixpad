# Table Refinement in `scan0`

## Overview
Gfm tables require recognizing columns separated by pipes `|` and the delimiter row (dashes).

## Rules
- **Column Separator**: Pipes `|` separate cells.
- **Delimiter Row**: Must follow the header row.
- **Alignment**: Delimiter cells contain `-`, `:` or ` ` (spaces).

## scan0 Responsibilities
- **Pipe Scanning**: Emits `TablePipe` for `|`.
- **Delimiter Row Marker**: Detects if a line consists only of pipes, dashes, colons, and spaces.
- **Row Separation**: The semantic phase will group lines into table rows.

## Table Delimiter Row Detection
A line is a delimiter row if:
- It contains only `|`, `:`, `-`, and spaces.
- It contains at least one dash.
- It must follow a header row (semantic responsibility).

## scan0 Implementation Details
- Detect if current line could be a table delimiter row.
- Emit a `TableDelimiterRowMarker` token at the start of such a line.
- The semantic layer will then confirm table structural integrity.

## Semantic Layer Role
The semantic phase will decide if a line with pipes is a table header, a table row, or a paragraph. A table header *must* be followed by a valid delimiter row.
- Column alignment (left/center/right) is extracted from the delimiter row.
- `TablePipe` tokens within a table row separate cell contents.
