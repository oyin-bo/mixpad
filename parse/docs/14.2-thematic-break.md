# Thematic Break Scanning in `scan0`

## Overview
Thematic breaks (horizontal rules) are created using runs of three or more `*`, `-`, or `_` characters.

## Rules
- **Minimum Chars**: 3 or more of the same delimiter.
- **Spaces**: Can have any number of spaces between characters.
- **Indentation**: Preceded by up to 3 spaces.
- **No Other Content**: The line cannot contain anything other than the delimiters and spaces.

## scan0 Responsibilities
- **Pattern Matcher**: Verify it meets the 3+ char requirement on the same line.
- **Block Priority**: Thematic breaks take priority over paragraph text or setext underlines (if they contain 3+ same-type chars and no spaces, they *could* be setext, but a thematic break is checked first in some contexts).
  - Note: `---` at the start of input is `FrontmatterOpen`.

## Implementation Logic
```javascript
export function scanThematicBreak(input, start, end, output) {
  const firstChar = input.charCodeAt(start);
  if (firstChar !== 42 && firstChar !== 45 && firstChar !== 95) return 0;

  // Max 3 indent from lineStart
  const lineStart = findLineStart(input, start);
  const lineIndent = countIndentation(input, lineStart, start);
  if (lineIndent > 3) return 0;

  let offset = start;
  let count = 0;
  while (offset < end) {
    const ch = input.charCodeAt(offset);
    if (ch === firstChar) {
      count++;
      offset++;
    } else if (ch === 32 || ch === 9) {
      offset++;
    } else if (ch === 10 || ch === 13 || ch === 0) {
      break;
    } else {
      return 0; // Invalid character found on line
    }
  }

  if (count < 3) return 0;

  output.push((offset - start) | ThematicBreak);
  return offset - start;
}
```
