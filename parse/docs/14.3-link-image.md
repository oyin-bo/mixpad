# Link and Image Scanning in `scan0`

## Overview
Links and images are complex inline structures. `scan0` provides the basic lexical markers, while `semantic.js` handles labeling and destination extraction.

## Token Types
- `LinkOpen`: `[`
- `LinkClose`: `]`
- `ImageMarker`: `!` (only when followed by `[` or `(`)
- `LinkDestOpen`: `(`
- `LinkDestClose`: `)`

## scan0 Responsibilities
- **Image**: Recognizes `!` followed by `[`.
- **Brackets**: Recognizes `[` and `]`.
- **Destination**: Recognizes `(` and `)`.
- **No Pairing**: `scan0` does *not* pair these up; it emits individual markers with length 1.

## Implementation Details
```javascript
case 91 /* [ */:
  output.push(1 | LinkOpen);
  return 1;
case 93 /* ] */:
  output.push(1 | LinkClose);
  return 1;
case 33 /* ! */:
  if (offset < end && input.charCodeAt(offset) === 91 /* [ */) {
    output.push(1 | ImageMarker);
    return 1;
  }
  break; // fallback to inline text
case 40 /* ( */:
  output.push(1 | LinkDestOpen);
  return 1;
case 41 /* ) */:
  output.push(1 | LinkDestClose);
  return 1;
```
The [link label](https://spec.commonmark.org/0.31.2/#link-label) can be several tokens long; the semantic phase will find the closing `]` and subsequent `(` to resolve the link.
